# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussion technical and constructive.
Harassment or discrimination of any kind is not tolerated. Report concerns privately to the maintainers
through [GitHub's private reporting](https://github.com/zigh2/ApkNamer/security/advisories/new) or the contact listed on the maintainer's profile.
