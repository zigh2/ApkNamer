# Security policy

## Supported versions
Only the latest release receives fixes.

## Reporting a vulnerability
Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(Security tab -> "Report a vulnerability", or [open a private report](https://github.com/zigh2/ApkNamer/security/advisories/new)) and include steps to reproduce.
You can expect an initial response within 7 days.

## Scope notes
APK Namer reads archives locally and never executes their content. It declares no network permission.
